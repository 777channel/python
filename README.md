# 机器学习项目代码与训练数据

本仓库汇总 OneDrive `python` 目录中的机器学习与数据处理源代码及训练 CSV 数据，作为私有代码备份和版本管理仓库。

## 内容

- `机器学习/`：模型训练、特征工程、缺失值填充、SHAP/PDP 分析等代码。
- `数据处理/`：数据清洗、转换和统计处理代码。

## 训练 CSV 数据

已补入 55 个训练及预处理相关 CSV，沿用 OneDrive `python` 目录的相对路径、文件名和原始内容。包括自然/人工老化、微塑料、缺失值填充、编码、特征工程和归一化数据；详见 [训练数据清单](DATASETS.md)。

部分脚本仍使用旧的本机绝对路径，运行前需要改为仓库中对应数据路径。文件名不同的数据版本不能直接相互替代。

## 未纳入仓库的内容

以下内容体积较大、可由代码重新生成，或不适合保存在 Git 中，因此继续保留在 OneDrive：

- `trained_models/`、`saved_models*/` 和其他模型权重；
- `.venv/`、缓存和编辑器配置；
- 清单以外的数据文件及 Excel 数据集；
- 图片、PDF、训练结果和其他输出文件；
- 第三方源码副本。

仓库包含清单列出的 CSV 数据，模型权重仍保留在 OneDrive。运行脚本前，请在本地配置对应的数据路径和 Python 环境。
