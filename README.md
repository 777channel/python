# 机器学习项目代码

本仓库汇总 OneDrive `python` 目录中的机器学习与数据处理源代码，作为私有代码备份和版本管理仓库。

## 内容

- `机器学习/`：模型训练、特征工程、缺失值填充、SHAP/PDP 分析等代码。
- `数据处理/`：数据清洗、转换和统计处理代码。

## 未纳入仓库的内容

以下内容体积较大、可由代码重新生成，或不适合保存在 Git 中，因此继续保留在 OneDrive：

- `trained_models/`、`saved_models*/` 和其他模型权重；
- `.venv/`、缓存和编辑器配置；
- 原始数据、CSV/Excel 数据集；
- 图片、PDF、训练结果和其他输出文件；
- 第三方源码副本。

仓库不包含 OneDrive 中的原始数据和模型文件。运行脚本前，请在本地配置对应的数据路径和 Python 环境。
